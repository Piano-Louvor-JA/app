# Ícones do aplicativo

Geometria SVG do [Tabler Icons](https://github.com/tabler/tabler-icons), licença MIT preservada em LICENSE-tabler.txt. Capturada em 16/10/2026. Canvas 24×24, traço 2, cor herdada por currentColor.

Os ícones são empacotados localmente e funcionam offline. AppIcon usa o ícone de fonte já existente apenas para nomes ainda não migrados.
